# Aulas-LABD

Um banco de dados é um sistema organizado para armazenar,gerenciar e recuperar dados,composto por um conjunto detabelas que possuem alguma relação entre si, estabelecida por meio de chaves (como chaves primárias e estrangeiras).
Tabelas são estruturas que organizam os dados em um banco de dados relacional.Cada tabela é composta por um conjunto
de campos (colunas) e registros (linhas).
